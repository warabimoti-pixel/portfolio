## 先に編集する箇所
- `index.html` のPythonプログラム名・概要説明を実際の課題04の内容に変更
- 高専祭プロジェクト名・活動概要・自分の役割を実際の内容に変更

## 画像の差し替え（重要）
`images/` 内の `python-1.svg`〜`python-4.svg` はPython課題の画像差し替え用、`festival-1.svg`〜`festival-4.svg` は高専祭プロジェクト画像の差し替え用です。これらは仮画像であり、課題提出に必要な実際のスクリーンショットではありません。

実際のスクリーンショットを同じ `images/` フォルダに保存し、`index.html` の該当する `<img src="...">` のファイル名を変更してください。Pythonは4枚以上、高専祭プロジェクトも4枚以上の実際の画像または動画を掲載してください。

## GitHub Pagesで公開
1. このフォルダの中身（`index.html`、`style.css`、`images`）をリポジトリ直下にアップロード。
2. GitHubの Settings → Pages を開く。
3. Sourceを `Deploy from a branch`、Branchを `main`、Folderを `/(root)` にしてSave。
4. 公開URLが表示されるまで待つ。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
